# AOMS Protocol (v1.1)

**A Decision Protocol for Dialectical Navigation** — a griftless, reproducible framework that combines ontological coherence and phenomenological evidence.

https://gnosisunderfire.com/2025/10/17/the-grand-unified-theory-of-phenomenal-plausibility/

## Quick Start
1. Read **PROTOCOL.md** (or the blog post) for the full method.
2. Use the **plausibility_ledger.csv** to log decisions (N-of-1 friendly).
3. Adopt a hypothesis when **P\* ≥ 0.51** (or **≥ 0.60** under the state guardrail).

### Core Update Rule (normalized)
- Score each candidate `sᵢ = P₀ · E · C · ρ` and normalize:  
  `P*(hᵢ) = sᵢ / Σⱼ sⱼ`, with default competitor `h₀ = "wait 24h"`.

### Scales (one glance)
- **E**: 0.2 vibe • 0.5 pattern • 0.8 direct NQ hit • 1.0 bullseye  
- **C**: 0.3 hand‑wavey • 0.6 axiom‑consistent • 0.9 elegant prediction  
- **ρ**: 0.2 meh • 0.5 somatic yes • 0.9 full‑body click  
- **State guardrail**: if mania/withdrawal/sleep < 6h → multiply ρ by 0.6 and raise threshold to 0.60.
